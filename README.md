# DigitalPass

DigitalPass is a Student Bus Pass Management System built with Django.

## Features
- Student Registration
- Authentication
- Document Upload
- College Verification
- Depot Approval
- QR Code Bus Pass
- Admin Dashboard

## Tech Stack
- Django
- Python
- SQLite
- Bootstrap 5
- HTML, CSS, JavaScript
